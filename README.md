# Nikhil Bondre — Narrative Portfolio

## Run locally
1. Extract the ZIP while keeping the folder structure intact.
2. Open `index.html` in a modern browser, or open the extracted folder in VS Code and use Live Server.
3. `dont-go-back.html` contains the interactive text-based narrative demo.

## Homepage
- `index.html` — portfolio homepage, featuring GENOCIDE, The Saxophone Thief, and RECON under **Featured Worlds**.
- The connected animated crime universe is presented after the featured projects.
- The “Stories don't just get told” section appears after the connected-universe section.
- Navigation, project cards, supporting-material links, and contact links are retained.

## Project pages
- `genocide.html` — dark-fantasy action RPG concept and Genjo showcase.
- `recon.html` — multiplayer strategy and organisation-management game concept.
- `saxophone-thief.html` — animated crime/noir project.
- `saxophone-thief-film.html` — related film page.
- `connected-universe.html` — connected animated crime universe overview.
- `saimon.html` — SAIMON project page.
- `universe-tba.html` — universe information page.
- `dont-go-back.html` — interactive narrative demo (uses `dont-go-back.js`).
- `peaks.html` — adventure/mystery animation concept.
- `shopkeeper-mystery.html` — short mystery story overview.

## Shared files
- `styles.css` — responsive styling and project-specific visual themes.
- `script.js` — responsive navigation and Genjo video controls.
- `assets/genjo-weapon-showcase.mp4` — video asset used by the GENOCIDE page.

## Notes
- Keep all files and the `assets` folder together; do not move individual HTML pages away from the shared CSS, JavaScript, or media.
- The site is a static website. Google Drive and email links require an internet connection.
- Project descriptions distinguish concepts and writing samples from shipped products or implemented game systems.
