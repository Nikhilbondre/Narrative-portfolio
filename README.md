# Nikhil Bondre — Narrative Portfolio (V4)

## Open locally
1. Keep all files and folders together.
2. Open `index.html` in a modern browser, or open this folder in VS Code and use the Live Server extension.
3. `dont-go-back.html` includes the interactive text-only narrative demo.

## Pages
- `index.html` — portfolio hub
- `genocide.html` — bounded, chapter-based 3D Soulslike-inspired action-RPG concept; includes the supplied Genjo weapon asset video and Genjo arena demo status
- `peaks.html` — snow/sky-blue animation project page
- `saxophone-thief.html` — 1990s animated crime/noir project page
- `dont-go-back.html` — branching text narrative demo
- `shopkeeper-mystery.html` — short mystery story overview
- `recon.html` — multiplayer strategy game concept, with a Drive portfolio link near the bottom of the page

All descriptions are based on the supplied portfolio documents. Projects are described as concepts or writing samples where appropriate; this site does not claim the concept-stage games have shipped or all proposed systems have been implemented.
